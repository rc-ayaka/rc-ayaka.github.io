“手风琴入门指北(施工中）”

Last updated on August 14, 2026 pm

写在前面

欢迎大家来到这里，从时间上看本人学习手风琴也有10年了（当然高中是有三年的断档的orz），身边的朋友也或多或少都对手风琴展现了一定的兴趣，因此想着把我对于手风琴的理解写成对应的一个入门教程便于大家的取阅。

本文不会有广义上的乐理，但也可能有些围绕手风琴的基本乐理进行适当展开，对于完全零基础的朋友我会尽量尝试都标注释义。
除此之外，市面上有着充足的手风琴教程，大家可以自行寻找。

总体而言，我认为手风琴的学习曲线呈现的是“凹”字型，上手较难，但是很快就可以演奏出很好的效果 （左手bass一键和弦太赖了bushi），再就是进阶演奏，可玩性非常高，弹好也很困难，乃至自由低音（移动小钢琴）。

想要更深入地演奏，有条件还是请专业老师较好，否则可能产生坏习惯。

1. 认识手风琴

手风琴种类繁多： 最常见的是键盘手风琴（piano accordion）、键钮手风琴/巴扬（button accordion/bayan） [1]，此外还有六角琴（concertina）、班多钮（bandoneon）、全音阶（diatonic button accordion/melodeon），除此之外是很多特定地区的变种：嘎拉莫尼、施泰里手风琴、瑞士风琴……

  1. 键盘琴（Piano accordions）: 1、2、13
  2. 全音阶（Diatonic button accordion）: 3
  3. 键钮琴（Chromatic button accordions）: 11、12、14
  4. 电琴（Digital accordions (V-Accordions, Roland Corporation)）: 11、12、13、14
  5. 班多钮（Bandoneon）: 4
  6. 英式六角琴（English concertina）: 5
  7. 盎格鲁-德式六角琴（Anglo-German concertinas (Anglo concertinas)）: 6、7、8、9、10

2. 结构

手风琴主要是由三大块组成：左：贝斯低音部、中：风箱、右：高音部

2.1 右侧琴身

这一部分就是手风琴的最核心的发声部分，有很多复杂的结构部件很难一一理清，就介绍一下最最重要的部分吧。

2.1.a 簧-键封门连杆机构（Pallet mechanism）

手风琴是活簧类（Free reed）乐器，当然有时候也被分为键盘类乐器，这当然是从发声原理和形态学的不同方式分类的。顾名思义，手风琴是由“风”产生的气流去使簧片振动，截断气流进一步发声。

注意，很多人误以为是金属簧片本身的机械振动发出了巨大的声音，但这是错误的❌，如果没有气流，仅靠簧片自身的振动（类似于音叉）发出的声音是微乎其微的。实际上，是气流 → 压迫簧片振动 → 截断气流，空间体积流量的剧烈变化向外发出猛烈且有穿透力的声响。后续有空闲会尝试详细分析手风琴振动发声原理。

图示即为手风琴的簧片，黄色的是皮革，起到单向阀的作用（现在量产簧会采用塑料片代替）；银色的就是活簧片，朝内起振。

而 封门盖（Pallet） 则控制了气流是否能通过音室使簧片振动。

如图所示，这张图很好的展示了整个连杆系统以及对应推拉风箱的气流走向。当按下按键时，封门盖会被抬起，从而使空气能够向各个方向进入音室，进而激发簧片发声；空气流动的方向取决于风箱的运动方向。类似的机制也应用于按钮式手风琴，以及左手 Stradella 这样的传统低音系统中，通过按下单个按钮来触发多个踏板的开启，从而实现多个音符的同时发声。

切换音色也是这样实现的，通过机械结构控制封门和音室之间开闭，实现不同音簧的发声与否

键盘排布上主要就分为俩类：键盘和键钮，当然也有其他比较特殊的存在（）

键盘很容易理解，和钢琴保持一致；

键钮（巴扬）琴初看很难，其实也是有迹可循的。键钮一般右手会至少4排，常为5排，甚至有6排的，排布主要看外侧三排。且键钮主要分为B系统和C系统，差异主要在于排布递进的走向不同：B系统是由内向外半音依次递增的，C系统则是反过来从外向内的。下面以B系统为例，

这两张图很好的展示了B系统的排布，其中白键、黑键对应的就是全音、半音。观察左图一个完整音区（1-7），想象一下现在你背着琴，从键盘上方观察这个音区（即从左图左端 → 右端，右图上端 → 下端）。依次从内斜向下向外，即1(C) → #1(#C) → 2(D) → #2(#D) → 3(E) → 4(F) → #4(#F) → 5(G) → #5(#G) → 6(A) → #6(#A) → 7(B) → 1(C)；颜色上：白黑白黑白白黑白黑白黑白白；也就是：全半全半全全半全半全半全全。这与钢琴是完全一致的排列不是吗？，有且仅有的是把一组自然音阶以3为单位颉取，再重新斜着码上去！C系统不过是沿第二列镜像对称一下而已，即音阶上升序列变为从外侧斜向下向内走动。


现在再来看看加上内侧两排（辅助排），看图很好理解，这是把外侧两排向着内侧的方向平移。与此同时，两个完全相同的音从结构上是由同一根连杆控制的，也就是按下相同的音，辅助键与正常键会同时下沉。这样设计的目的，是方便我们演奏者能方便的转换把位，否则在演奏复杂和弦和快速跑动时，在三排情况下，手很容易拧成麻花（笑😇）

转调 是上天送给巴扬的礼物🎁！在五排键下，转调不需要改变手型就能完成。

2.1.c 变音器(Register)

手风琴的音色系统借鉴了管风琴的“英尺（Foot）”标记法。不同长度的音簧决定了声音的音高八度。现代标准的全尺寸手风琴（无论是巴扬还是键盘）右手通常包含三排（LMM）或四排（LMMH）音簧：

  • L (Low) — 16英尺 (16’)：低音簧片
    比标准音低一个八度。声音深沉、浑厚，通常被称为巴松（Bassoon）。

  • M (Middle) — 8英尺 (8’)：中音簧片（基础音）
    标准音高，也就是乐谱上实际写出的音高。声音纯粹、直接，被称为单簧管（Clarinet）。

  • M+ / M- — 8英尺 (8’)：移频中音簧片（颤音簧）
    同样是标准音高，但在调音时会比主M簧片稍微调高（Sharp）或调低（Flat）几个音分（Cents）。当它与基础M簧片同时发声时，两者频率的微小差异会产生声学上的“拍频（Beats）”，从而形成手风琴标志性的颤音（Tremolo）。

  • H (High) — 4英尺 (4’)：高音簧片
    比标准音高一个八度。声音清脆、穿透力强，被称为短笛（Piccolo）。

变音器按键上看到的那些带有圆点的圆圈，其实是内部音簧开合状态的直接缩影。圆圈被两条横线分为上、中、下三层：

  • 上层（Top）： 代表高音簧片（H / 4’）。这里最多有一个点。

  • 中层（Middle）： 代表中音簧片（M / 8’）。这里可以有1到3个点并排（取决于乐器是单颤音还是双颤音缪塞特）。最中间的点通常代表基础M簧，两侧的点代表调偏的颤音M簧。

  • 下层（Bottom）： 代表低音簧片（L / 16’）。这里最多有一个点。

黑点意味着按下了该变音器后，内部的遮流板（Slider）会打开，气流可以通过该排音簧；空白则意味着气流被阻断。

变音器的形式也有很多种：

  1. 传统变音器（键盘/盖板侧）
    这是最常见、也是绝大多数手风琴的标配。它们并排安装在右手键盘（或巴扬键钮）旁边的音箱盖板（Grille）上。

  1. 下颌变音器（Chin Registers）
    这个设计真的很棒！常见于比较高级的型号上（啊啊啊真的很馋🥹）。它们通常被安装在右手音箱的最顶部，直接对着演奏者的下巴。需移动双手，只需稍微低头，用下巴（Chin）去触碰或滑动这些按键即可瞬间完成音色切换，无需打断乐句。

  1. 拇指变音器
    这种变音器位于右手键盘（或键钮）的边缘，也就是最靠近演奏者身体、右手拇指平时靠着的那条长条形侧边。大拇指只需向内侧轻轻一压即可触发。这种琴多见于法式流行琴（你怎么知道我的琴就是这样的🥳，讲道理感觉不是很方便，除了可以给不懂手风琴的人装个比：怎么能突然改变音色🤯）

  1. 掌侧变音器（Master Bar）
    它通常不负责所有音色的切换，而是作为一个“一键全开（Master / Tutti）”的快捷键。当演奏者在单簧管或巴松等单簧片音色下演奏完毕，需要立刻进入气势磅礴的和弦合奏段落时，掌侧一压就能瞬间打开所有簧片。

机械小知识：
变音器本质上是一个气路开关。在风箱的压力下，当按下不同的变音键，键盘下方铝制排孔板上的滑板会发生平移，露出或遮盖住通向特定 簧框（Reed block） 的气孔，从而阻止或允许特定组簧片的发声。

2.2 风箱（Bellows）

风箱是手风琴的 灵魂，音量大小与拉动风箱的力度成正比。在手风琴中，键盘本身没有太多的力度反馈控制（当然 压音（Bending） 这类进阶技巧仍然是通过控制按下的幅度从而实现的）。因此，所有乐句的情感表达都依赖于风箱的控制。断奏、颤音、重音、抖风箱等演奏技法也都是由风箱完成的。

⚠️不按键时，千万不要硬推拉风箱！这样相当于强迫手风琴打开一个气口，会损坏手风琴的内部结构，导致风箱漏气。

2.3 左侧琴身

这一部分就是手风琴低音伴奏的发声处，类似于右手，同样主要是三大块：键盘、贝斯机、变音器。

除此之外，在正左侧上方还有一个单独的 气门 按钮（air button），它与其他键的区别是它不对应任何簧片的气口，因此按它推拉风箱不会发声的同时能使风箱内部和外相连，进而调整风箱的位置。

2.3.a 键盘排列

左手的低音存在俩大类（均为键钮形式）：传统低音与自由低音。两者的区别在于前者无音高，同时能够一键和弦：即按下一个键就能发出至少3音的和弦；后者有音高之分，且与右手相同，一键一音（其实就和钢琴没差啦~），能够演奏更为复杂的音乐如复调之类的。由于后者已经几乎隶属于专业方向了，并且我也不太懂，这里仅着重介绍前者。

传统低音，目前市面上99%以上都是 Stradella 贝斯系统（Stradella Bass System），也称为标准贝斯系统，排列方式为 五度循环（……♭B - F - C - G - D - A - E - B - #F - ……）。这样，一个调式中的主要大调音（I、IV 和 V 音）就被安排在了三列相邻的按键位置上。

上图为 Stradella 系统的排列方式。每一排上的键钮代表了以某音为根音的一系列单音或和弦，从上往下（风箱侧到手侧，斜向右侧为同一排）：

  • 第二列： 根音列（单音），演奏时依靠主要就这一列定位其他键位（如同键钮右手，在C以及其他音会刻有 凹槽 & 花纹 辅助定位。
  • 第一列：根音列的 大三度音，一般称为 对位低音（counterbass）
  • 第三列：根音构成的 大三和弦，即根音+大三度音+五度音；
  • 第四列：根音构成的 小三和弦，即根音+小三度音+五度音；
  • 第五列：根音构成的 属七和弦（缺五度音），即根音+大三度音+属七度音；
  • 第六列：根音构成的 减七和弦（缺五度音），即根音+小三度音+六度音。

我们在谈论多少多少bs的手风琴，指的就是左手的键钮数，而不是绝对的音数。譬如上图：6 * 20 = 120 个键，所以这就是120 贝斯的手风琴。

衍生出 5 排变体： 既然减七和弦可以由属七和弦或其他和弦的组合来替代，一些中小型手风琴（如 72 贝斯或 80 贝斯）为了减轻琴身重量、简化内部机械，干脆直接去掉了最外面的减七和弦排，从而形成了 5 排按键的变体。

省略7和弦5音：在和声学中，决定一个和弦性质（是明亮、忧郁还是紧张）最核心的音是三音和七音。5音大多时候只是起一个厚度支撑的作用。在手风琴低音区本来就容易浑浊的情况下，去掉5音不仅不影响和弦的色彩，反而能让伴奏听起来更加干净利落。同时，少吹一组簧片能节省下很多的风箱气量，也变相砍掉了横轴数量，简化了内部机械结构，进而降低了故障率。这也使得产生了神奇的和弦替代 ：Cdim（C-Eb-A） 和 Adim（A-C-Eb） 实际发出的音是完全一样的，利用这一点能实现更丰富的旋律走向。

此外，Stradella 系统在百年演变间，为了适应不同需求也演化出了许多变种：

标准的 2 排低音（基本低音 + 大三度对位低音）在弹奏简单的“动-次-打-次”伴奏时非常高效。但当遇到法国香颂（Chanson）、爵士乐或复杂的复调时，演奏者需要弹奏流畅的低音音阶（Bass Runs）。

  • 3 排低音系统（3 Bass Rows）： 如图中的 A、B、Bx 系统。它们在标准的两排低音之外，增加了一排小三度（Minor 3rd）对位低音。

  • 这样一来，演奏者在弹奏音阶或复杂的低音旋律时，手指的跨度会大大减小，不需要在贝斯板上大幅度上下跳跃，运指更加符合人体工程学。这在法国和部分欧洲国家非常流行。0人问但是主包的琴就是 3 Bass Rows A😋

2.3.b 贝斯机

在右手键盘上，一个按键对应一个气门，这是直接的线性控制。但在左手，为了实现单指按压就能发出由三个或四个音符组成的和弦，内部采用了一种 “矩阵式” 的连杆触发结构。

  1. 纵向按键杆（Pushrods）： 图中最上方连接着键钮的那些密密麻麻、平行排列的细长金属直杆。
  2. 金属销钉（Pegs）： 在这些纵向直杆的侧面，会看到焊在上面的一些细小金属凸起或者说小齿。每个和弦键的杆子上会有三个对应不同音高的销钉。
  3. 横向传动轴（Transverse Shafts）： 位于纵向杆下方，与它们呈90度垂直交错的那几十根横向金属细轴，有着很多不规则突触，与销钉相搭，进一步传动。
  4. 触点（Touchings）： 横向轴转动时联动这部分下压，使簧片打开。

这个视频比较直观地展示了贝斯机联动的状态，注意观察画面正上方白色的部分，那里就是触点，下压使气门打开发声。（不建议去看这个人视频，维修是没有的，废话是连篇的……）

与右手变音器类似，左手一般同样能够更改音色。
